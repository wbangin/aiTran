隐私说明

aiTran v0.3.21 · 更新于 2026-09-25

没有会员、账号和统计

aiTran 不提供登录、会员、广告或行为分析服务，也没有 aiTran 运营的翻译中转服务器。

本地保存的数据

  • 扩展设置与自定义服务配置
  • 自定义 API Key
  • 本地翻译缓存

翻译请求

待翻译文字、语言参数和必要上下文（如页面标题）直接发送给所选的 Google、Microsoft 或自定义服务。邮件、聊天等文字可能包含个人通信。测试连接会发送示例文字并可能消耗额度；服务方还会收到连接必需的网络信息，例如 IP 地址。

自动翻译默认关闭；开启后会按设置自动处理后续受支持网页及动态文字。免费服务自动回退默认开启，Google 或 Microsoft 请求失败时可能将待翻译内容转交另一内置服务；可在设置中关闭。自定义服务不会因此切换到内置服务。

密钥与传输

API Key 保存在 chrome.storage.local，通过 Authorization 请求头发送给对应自定义接口鉴权，不会随构建或发布 ZIP 导出。不读取浏览器保存的密码、登录 Cookie 或 ChatGPT/Codex 登录凭证；跳过密码输入框。浏览器本地存储不是专用加密保险库，请勿公开配置或包含密钥的截图。第三方响应可能含敏感信息，分享错误前请先检查。

内置服务及自定义公网、局域网 API 使用 HTTPS。HTTP 仅允许 localhost、127.0.0.0/8 或 [::1] 本机回环地址；接口请求不携带登录 Cookie，也不跟随重定向。本机服务是否继续转发由其自身决定。

文档翻译

PDF 和其他文档在浏览器本地读取并提取文本，原始文件不会上传到 aiTran 服务器。提取出的待翻译文本会发送到你选择的翻译服务。

AI 页面总结

点击「生成总结」时，页面标题和提取出的正文会发送到你在总结面板选定的 AI 服务。输入框、可编辑区域和扩展生成的译文不会包含在正文中。总结仅保留在当前页面面板，不写入翻译缓存。

标题最多 500 字符，正文最多 24,000 字符。请先了解所选服务的隐私政策、费用、保留和训练使用规则，不向不可信接口提交敏感内容。

本地保留与删除

设置、服务 URL、模型、提示词与 API Key 保存在本地扩展存储；译文、散列缓存键和时间信息保存在本地 IndexedDB，最多 5,000 条。无浏览历史采集或 Chrome 同步存储上传。删除服务并保存可移除其配置和密钥，但不会撤销服务端密钥或清除缓存。卸载扩展或清除其浏览器存储可移除本地设置和缓存；第三方数据的删除需联系对应服务。

权限与有限使用

storage 保存设置，contextMenus 提供右键入口，主机权限用于网页文字处理、双语展示及连接用户配置的服务。浏览器受保护页面不能翻译。不申请 tabs、activeTab、history 或 nativeMessaging 权限。脚本和 PDF Worker 随安装包提供，不执行远程代码；远程 API 仅返回数据。

aiTran 对用户数据的使用遵守 Chrome 应用商店用户数据政策，包括有限使用要求。仅为上述用户可见的翻译与文字理解功能处理数据，不出售数据，不用于广告、与单一用途无关的目的、信用评估或贷款决策。第三方服务另有其政策和条款。

联系

通过 项目 GitHub Issues 联系维护者。公开反馈不要附带密钥、私密正文或登录凭证；敏感问题请先请求私下沟通渠道。政策变更以更新日期和版本标明。
