隐私说明

aiTran v0.3.8

没有会员、账号和统计

aiTran 不提供登录、会员、广告或行为分析服务，也没有 aiTran 自己的翻译中转服务器。

本地保存的数据

  • 扩展设置与自定义服务配置
  • 自定义 API Key
  • 本地翻译缓存

翻译请求

当你主动使用翻译功能时，选中的文本会直接发送给 Google Translate、Microsoft Translate 或你配置的自定义 URL。API Key 只用于向自定义 URL 发起请求。

文档翻译

PDF 和其他文档在浏览器本地读取并提取文本，原始文件不会上传到 aiTran 服务器。提取出的待翻译文本会发送到你选择的翻译服务。
