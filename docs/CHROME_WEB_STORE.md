# aiTran v0.3.21 — Chrome 应用商店填写资料

核对日期：2026-09-25。请先上传 `aiTran-0.3.21-chrome.zip`，再填写以下资料。不要继续使用 v0.3.18 的权限说明。

本轮已移除 `tabs`、`activeTab` 和重复的固定域名权限；保留 `storage`、`contextMenus`、`<all_urls>`。已补全隐私政策，远程自定义接口强制 HTTPS，HTTP 仅允许本机回环地址，接口禁止重定向。本文不是审核通过保证，也不代替发布方确认政策、验证邮箱或保存后台草稿。

## 1. 单一用途说明 — 直接复制

aiTran 的单一用途是帮助用户翻译和理解浏览器中的文字内容。扩展围绕这一用途提供网页双语对照、选中文字翻译、悬停翻译、输入框翻译、文本及文档翻译，以及当前页面的 AI 摘要。用户可选择翻译服务、目标语言和显示方式，翻译或摘要结果显示在当前网页或扩展页面中。

## 2. 远程代码

选择：**否，我没有使用远程代码。**

如后台允许补充说明，可复制：

aiTran 不从远程服务器下载并执行 JavaScript、WebAssembly 或其他可执行代码。扩展脚本、界面及 PDF 解析 Worker 均随安装包提供。联网请求用于向翻译服务或用户配置的 API 提交文字并获取 JSON、译文或摘要；返回内容作为数据解析和展示，不作为代码执行。

调用远程 API 不等于使用远程代码。若后台仍要求理由，检查“否”是否已保存及当前草稿的包版本，不要选择“是”后编写不存在的用途。

## 3. 主机权限理由 — 直接复制

aiTran 需要在用户授权的不同网站及其内嵌框架中识别可翻译文字、显示双语译文和悬浮工具，支持用户启用的划词、悬停、输入框及自动翻译功能。用户需要翻译的网站无法预先列举，因此申请全站主机权限。扩展还需要访问 Google、Microsoft 翻译接口及用户自行填写、域名不固定的自定义翻译或 AI API。待处理内容仅用于翻译与文字理解，不用于广告或浏览行为分析。自动翻译默认关闭，用户开启后会按设置处理后续受支持页面。自定义远程接口要求 HTTPS，HTTP 仅允许本机回环地址。

新包仅声明 `<all_urls>`，不再重复列出 Google、Microsoft 的固定主机地址。浏览器内部页面和商店等受保护页面仍不可访问。

## 4. storage 权限理由 — 直接复制

用于通过 chrome.storage.local 在用户当前浏览器中保存翻译服务选择、源语言和目标语言、双语显示模式、页面功能开关、自动翻译和备用服务偏好、悬浮球透明度，以及用户填写的自定义 API 地址、模型、提示词和 API Key，以便重启浏览器后继续使用。扩展不将这些设置同步到 aiTran 服务器，不用于广告或行为分析。翻译结果缓存另存于本地 IndexedDB。

## 5. contextMenus 权限理由 — 直接复制

用于在网页、选中文字和可编辑区域的右键菜单中提供翻译网页／显示原文、翻译选中文本、翻译输入框、AI 总结当前网页及打开文本翻译等入口，使用户能够直接对当前内容调用翻译和文字理解功能。

## 8. 详细说明 — 整段复制

aiTran 帮助你翻译和理解网页文字，把网页双语阅读、文本翻译和 AI 页面总结放在简洁的界面中。

【网页双语翻译】
一键翻译当前网页，支持双语对照与仅显示译文，也可恢复原文。选择源语言、目标语言和翻译服务，让阅读更符合你的习惯。浏览器内部页面、扩展商店等受保护页面不支持翻译。

【随手翻译】
支持选中文字翻译、按修饰键悬停翻译段落，以及通过快捷键或右键菜单翻译输入框中的文字。各项功能可按需开关。

【AI 页面总结】
连接你配置的 OpenAI Chat Completions 兼容 API，选择总结语言，提取当前页面已加载正文的核心结论和关键要点。需要自行配置可用的 API 地址、模型及服务要求的密钥；第三方服务可能收费，额度及费用由对应服务提供方决定。长页面可能截断，总结不代表涵盖全部内容。

【文本与文档翻译】
提供独立文本翻译工作台，支持 PDF、TXT、Markdown、HTML、SRT、VTT 文件。文件在浏览器本地读取和解析，提取的待翻译文字会发送到所选服务，不是离线翻译。可复制或下载翻译结果。

【自由配置】
内置 Microsoft、Google 翻译服务接入，也支持自定义 API。可调整语言、显示模式及页面功能。AiT 悬浮球提供常用操作，支持透明度设置和实时预览。

【隐私与安全】
aiTran 无账号系统、广告或行为分析，不运营接收翻译内容的中转服务器。待翻译文字直接发送到所选服务。自动翻译默认关闭，开启后会按设置自动发送网页中待翻译的文字。免费服务自动回退默认开启，失败时可能转交另一内置服务，可在设置中关闭。生成 AI 总结时，页面标题和提取的正文会发送到选定的自定义 API。

设置、API Key 和翻译缓存保存在本地浏览器；API Key 仅发送给对应接口鉴权，不随安装包分发。自定义远程接口要求 HTTPS，HTTP 仅允许本机回环地址，不跟随接口重定向。服务提供方的数据处理、可用性、限制和费用以其政策为准。请勿向不可信接口提交敏感内容。

## 9. 数据使用表单

不要因“没有开发者自有服务器”而填“完全不处理用户数据”。当前实现会读取文字并传输至第三方，应按后台定义如实填写。

重点核对以下类别：

- **网站内容**：网页正文、选中文字、输入的文字、文件提取文字及页面标题等上下文。
- **个人通信**：用户翻译邮件、聊天等页面或主动提交的通信文字时会涉及；不是后台采集全部通信。
- **身份验证信息**：用户主动填写的第三方 API Key 在本机保存并发往对应接口；不读取浏览器密码或登录 Cookie。
- **网页浏览记录**：没有 history API 或浏览历史采集，但会处理当前页面标题。如果后台定义包含页面标题等元数据，应覆盖这一实际用途；不要写“完全不读取页面信息”。

其他类别按照后台定义和实际处理场景核对，不要无依据地全选或全不选。一般网络连接会向服务方暴露 IP，不代表扩展有地理定位功能。

用途补充说明可复制：

文字及必要上下文仅用于用户可见的翻译、双语显示和 AI 页面摘要；请求直接发送给所选翻译服务或用户配置的 API。服务密钥用于对应接口鉴权。设置与翻译缓存保存在本机，总结仅保留于当前页面面板。扩展不出售数据，不进行广告追踪、浏览历史分析或信用评估。
